# SOC Incident Commander (CompTIA Security+ SY0-701 Edition)

**Live Simulator:** [Play in Browser](https://goodalegg1993-hub.github.io/soc-incident-commander/)

An interactive, browser-based Security Operations Center (SOC) and Performance-Based Question (PBQ) incident response simulator built to reinforce **CompTIA Security+ (`SY0-701`)** objectives, root-cause diagnostics, and GRC decision-making.

### Key Features
- **Triage & Incident Response Tickets:** Hands-on scenarios covering endpoint telemetry, access controls, network anomalies, and containment workflows.
- **PBQ Lab Simulations:** Practical configuration and diagnostic challenges modeled on real-world SOC escalation paths.
- **Mentor Debriefs:** Immediate architectural and governance breakdowns explaining *why* each remediation step reduces operational risk.
